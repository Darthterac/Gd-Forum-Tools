# Gd-Forum-Tools
This is a userscript that runs a little addon for General Discussion forums. Its primary goal is to hide topics as your scrolling so you dont see topic posts from users you have ignored.

Load the code into TamperMonkey as a new script, just copy paste and save, make sure it is enabled. Have your UserID ie carla-0998038 ready to enter in which will sync your account ignores along with Topic ignores you can type in manually.

Look at these screen shots, the minimize button shrinks the modal to a avatar sized pill and toggles open when clicked, The private profile tracking is useful over time, most hidden profile people are snarky as heck so its good to know what topics they are attracted to, if your looking to avoid the drama.

Exports as a csv or the copy button to grab all that 'private' data, It will find alts with the same usercard and record that with the last post and time they were seen.
